# Sistema de Apoio ao Programa Saúde na Escola (PSE) - AEP

Aplicação desenvolvida em Linguagem C para auxiliar equipes de saúde e educação no planejamento, registro e acompanhamento de ações coletivas do PSE voltadas à saúde mental e prevenção de doenças negligenciadas, respeitando a LGPD.

## Como Compilar e Executar

Para compilar e executar o código-fonte em um ambiente operacional padrão (Linux, macOS ou Windows via GCC/MinGW), siga os passos abaixo:

1. **Pré-requisito:** Certifique-se de possuir um compilador C instalado (ex: GCC).
2. **Abra o terminal:** Abra o terminal (Prompt de Comando, PowerShell ou Git Bash) na pasta onde o arquivo do código-fonte está salvo.
3. **Compile o código:** Execute o comando de compilação abaixo para gerar o executável:
   ```bash
   gcc main.c -o pse_app
